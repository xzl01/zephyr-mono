# 设备端 Wi-Fi 配置

这项功能的目标是在 Mono 本机完成配网，不依赖手机网页、Mac 写入凭据或临时固件。

## 操作

1. 进入 **设置 → Wi-Fi 网络**。页面扫描附近的 2.4 GHz 网络，最多保留信号最强的 16 项，每页四项。
2. 轻触网络名称。开放网络直接提交连接；WPA2 网络打开密码键盘。
3. 密码键盘支持大小写、数字、符号和空格，长度 8–63 个可打印 ASCII 字符。默认隐藏，点击「显示」可核对完整密码。
4. 点击 **保存并连接**。提交成功只表示后台接受请求；页面随后显示真实的连接中、失败或已连接/IP 地址状态。
5. 保存的网络会在以后启动时自动连接，也可点击 **重新连接**。
6. **忘记网络**需要单独确认，会清除已保存的凭据、断开连接并更新设备接入点与网页配对码；不删除 TF 内容。

返回密码页外、回首页、提交成功或进入休眠都会清除 RAM 中的输入草稿；取消不保存新密码。

## 范围与限制

- 支持 2.4 GHz 开放网络和 WPA2-PSK。隐藏 SSID、WEP、企业认证、WPA3-only、5 GHz 网络不支持。
- 中文 SSID 可从扫描结果选择；密码不提供中文输入法。
- 密码不写入日志，触摸日志不记录可用于反推密码的按键坐标。设置/NVS 中仍保存用于以后重连的凭据；本轮不声称存储加密。
- 扫描、NVS 写入和连接交给独立网络工作队列；后台不操作 LVGL。扫描结果完成后才更新列表，不在每个 AP 回调时刷新屏幕。
- 墨水屏不是手机屏幕，输入反馈受物理刷新速度限制。同一键盘布局下的按键保序排队；切换布局/页面时拒绝过渡期触摸，避免旧坐标误触新控件。队列溢出会阻止提交，并要求重新输入，不静默提交缺字的密码。
- 扫描 30 秒超时会显示失败。由于 Zephyr 没有扫描事务 ID/取消接口，若驱动永久丢失完成回调，将隔离该次扫描直到完成回调或设备重启，不把迟到结果混进下一次扫描。
- 当前只保存一个网络，不是多网络漫游管理器。

## 验证记录

- 纯 C 键盘：全部 95 个可打印 ASCII、容量 32/63、边界、间隙、安全擦除；严格 C17 与 ASan/UBSan 通过。
- 网络后端：直接编译生产 C 的 fake-driver 行为测试，覆盖扫描结果/排序/去重、同步回调、错误、超时隔离、异步凭据保存、重连和忘记。
- 原生 UI：`bash tests/preview/build.sh` 以真实 LVGL、480×800 I1 和 64 KiB LVGL heap 渲染合成状态；不是硬件照片或真实联网记录。附加交互断言调用真实 `wifi_event`/`process_event`，覆盖取消、草稿保留/擦除、busy、忘记确认和输入 epoch。后端返回值是可注入 stub，不冒充真实联网测试。
- 固件构建与内存预算检查通过。构建镜像不包含固定测试 AP/密码或路由器凭据。
- **设备端走查（2026-10-21）**：生产固件已刷入，TF 正常挂载。用户明确确认在 Mono 上打开网络列表、用本机键盘输入密码并保存连接；随后 `GET /api/v1/status` 返回 `connected: true`、`station_ipv4: 192.168.8.198`。此交互证据来自用户走查确认，不是本工具直接观察键盘或照片。
- **非破坏性重启验证**：一次软件复位发现已有最近阅读记录触发的 `load_recent_callback` 空 suffix 解引用；修复 Zephyr 精确 Settings 子树回调的 `key == NULL` 约定，并同时修复阅读状态、信息缓存和 overlay 的同类回调。未清除 NVS/TF。修复后刷入启动正常，再执行一次不刷写的软件复位，启动证据通过，约 47 秒时 HTTP 验证自动重连同一路由器，`media: 1`、`ap: false`。
- 本轮真实覆盖本机输入/连接（用户确认）、软件复位与保存网络重连。错误密码、开放网络和“忘记后重新输入”的硬件组合没有逐项实测；其状态机与错误/取消分支由主机回归覆盖，不扩充为整机认证结论。
