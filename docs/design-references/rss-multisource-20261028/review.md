# 独立复核记录

本次扩展保留既有 480×800 I1 中文纸面设计。用户确认内容中心网页管理订阅，宽表按列分组翻页。

| 发现 | 修复与验证 | 结果 |
| --- | --- | --- |
| 慢 GET 重新加载覆盖用户的新草稿 | 编辑版本及请求序号隔离，加载期间禁止保存；延迟 GET 下编辑/新增/移除回归；同路径桌面、手机截图 | resolved，独立窄验收 ship |
| 无后续数据或提前拒绝的请求占住 HTTP 动态资源 holder | 保留框架 holder，拒绝 MORE 交由 core ABORT 释放；30 秒截止关闭当前 owner 的读取侧；持锁防 FD 复用；系统队列 K_NO_WAIT，锁忙 100 ms 后重试 | resolved，第二名只读 reviewer 确认 |
| JSON 转义使合法字节上限名称提前超限 | 扩展 wire 容量，解码后仍按 15/47/191 B 限制 ID/名称/地址 | resolved，独立边界复核 |
| 畸形 UTF-8 吞掉控制字符，可能把两列表格变为三列 | 完整 scalar 校验，坏字节逐一推进重新扫描；800 行控制字符矩阵、解析到 SD 再重读测试 | resolved，独立窄复核 |
| 实机连续短请求在 HTTP handler 前被拒绝 | 独立代码/ELF 容量复核确认 4 个 net_conn 项不足；改为 7，匹配 6 个 socket context 加 DHCP 独立登记；最终 DRAM 84.98% | 20 次复用连接及 12 次间隔短连接实机复验均通过，范围见 validation.md |
| 过期 AP 恢复、handoff 和 health 任务可能在 STA 状态已改变后仍执行 | 取消加执行时状态检查，关联期间延后 health；明确保留路由器失败、显式命令及暂停路径 | 独立窄复核与真实函数生命周期回归通过 |
| AP 启动完成事件晚于 STA 成功时漏排 handoff | AP_ENABLE 成功且 STA 已连接时补排 20 秒关闭；精确事件顺序及 STA 失败反例 | resolved，独立复核通过 |

首轮可视复核覆盖全部 18 张有效图片；布局未列出其它实质性缺陷。表格复核覆盖混排顺序、首列固定、分组表头、长格尾部和分页范围。后续窄验收只对列出的修复作结论，没有重新开展全表面审查。

设备真实网络与物理触摸验收单列于 `validation.md`，未以主机替身测试代替。
