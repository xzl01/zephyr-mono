# Field Notes 软件验收（2026-09-30）

本记录针对新设计候选，不能继承旧镜像的刷机或实机验收结论。
[主机预览](overview.png) 使用测试内容，输出为 480×800、I1；不是物理墨水屏照片。

## 已验证

- `sh tests/host/run.sh` 返回 0，包括分页、缓存、标点禁则、共享命中区域、完整基础 CJK 回退、24 小时所有时刻的大时钟宽度和 11 个二值透明度图标。
- 本地辅助主机 LVGL 使用项目依赖版本及 64 KiB 分配器；五个页面均有有效输出，首页/启动器黑像素占比低于 7%。64 位主机对象与设备 32 位 ABI 不同。
- 使用实际 UI 事件处理函数验证继续阅读、书签、TXT 菜单、EPUB 当前章节目录、底部导航、不可点击间隙和第二页空白，以及十次首页/启动器绘制切换。
- 三个现有构建目录增量构建均返回 0；内部 DRAM 均低于项目 85% 门槛。

| 配置 | 构建目录 | 内部 DRAM |
| --- | --- | --- |
| 默认 | `build-recovery` | 81.33% |
| 局刷演示 | `build-recovery-partial` | 76.45% |
| 驱动自检 | `build-recovery-selftest` | 77.12% |

默认候选 Flash 占用约 4.27 MB、静态 PSRAM 占用约 3.83 MB（8 MiB 的 45.70%）；LVGL 池位于 PSRAM，为大字形缓冲从 32 KiB 调整为 64 KiB。

> PSRAM 按运行期实际占用统计：`_ext_ram_end - _ext_ram_start`，即
> 2,784,800 bytes 的 `.ext_ram.bss` 加 1 MiB `CONFIG_ESP_SPIRAM_HEAP_SIZE`
> 预留堆。不要用 `.ext_ram.data` 段的尺寸代替：它前面还有一段
> `.ext_ram.dummy`（4 MiB、`NOLOAD`），只是为了让 SPIRAM 与 `drom0_0_seg`
> 共用总线地址时不重叠而做的对齐占位，不计入占用。按段尺寸统计会把它算进去，
> 得到 6.98 MB / 83.20% 的错误结论。
