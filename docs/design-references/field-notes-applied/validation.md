本轮按 `field-notes-expanded` 与 `field-notes-remaining` 中已确认的参考图，
实现书库、微信读书、日历、待办、便签、内容中心、遥控器、信息卡片、硬件工具、
设置、电源和系统状态，以及阅读菜单、目录、书签、详情、空状态和确认流程。
首页、应用索引与阅读正文保留此前已确认的视觉方向。

提交前已将设计与工作区其他电源、触摸、内容服务和存储改动分离。
下述主机检查、42 张原生截图及三种固件构建均在独立设计快照上重新通过；
42 张截图与此前混合工作区的对应截图逐张一致。其他改动保留在工作区。

## 实际渲染

[预览总览](overview.png) 和本目录 42 张独立截图均来自实际 C 界面代码与
LVGL 的 480×800 I1 渲染。测试文件由实际内容模型解析；硬件、连接、配对码、
电压与信息源为主机夹具，EPUB 目录为界面夹具。它们不是设备照片或实测数据。
`manifest.json` 记录页面、源码与图片 SHA-256。总览缩小图片时可能丢失 1 px
线条，应以独立 480×800 截图判断边框。

最初辅助预览器使用较大的主机内存池；发现后已重新编译实际分配器与 TLSF，
全部 42 个画面均在 65,536 bytes 配置下重新绘制。报告的最大峰值使用为
27,776 bytes，最小连续空闲块为 35,712 bytes。主机是 64 位 ABI，仍不能替代
设备上的 32 位运行期堆验证。辅助渲染与事件断言工具位于本机
本机临时预览目录，不是仓库的跨平台测试依赖。
