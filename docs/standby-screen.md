# 休眠屏

进入深睡前绘制的一帧静态画面，唤醒后由正常界面覆盖。因为画面保持不动，
**不显示时钟**：冻结的时间会立刻变成误导信息。

## 版式

- 左对齐 `x=22`，内容宽 436，与其余页面共用页头/页脚锚点（116 / 724）。
- 主视觉是 Bodoni 数字的"日"，旁边是月份与星期。
- 右侧栏显示最近的二十四节气和当日固定纪念日；表外年份不猜测，直接不显示。
- 天气行标注数据时间，未同步时明确写"天气未同步"。
- 中间内容带固定 `424–640`，按设置切换，其余元素坐标不变。

## 设置

`设置 → 休眠屏摘要`，可循环选择：摘抄 / 未来 8 小时 / 阅读进度 / 明日预告 / 留白。
选择存入 `papermono/sleep_summary`，与主设置记录分开，避免改变记录结构。

当前已实现：**摘抄**（内置 14 条公版短句，按日轮换）与留白；其余三项先保留选择入口，
内容带留空，待数据源就绪后补齐，不会伪造内容。

## 数据

- 节气：固件内置 2026–2027 两张准确表（来源为公开发布的节气时刻），每年 24 条；
  其它年份 `term_valid=false`。
- 纪念日：仅公历固定日期（元旦、植树节、世界地球日、世界读书日、劳动节、教师节、
  国庆节、圣诞节）；农历节日需要农历表，暂不提供。
- 摘抄：短句 + 书名 + 作者，按年内日序取模，保证同一天稳定。

## 验证

- `tests/host/test_almanac.c` 覆盖节气、距离、纪念日、表外年份和不合法日期。
- `tests/host/test_quotes.c` 覆盖每日轮换稳定性和非法输入回退。
- `tests/preview` 新增 `sleep` fixture，用真实 LVGL 渲染 480×800 I1 画面；
  产物见 `docs/design-references/sleep-screen/render-lvgl.png`。
- 尚未实机验证；天气与"下一日程"仍是占位文案。

## 唤醒方式

触摸唤醒已关闭：屏幕贴着纸张/布料时误触太频繁，一次擦拭就会把设备点亮。现在只有
侧键和电源键可以唤醒。休眠屏提示同步改为“按电源键唤醒”。
