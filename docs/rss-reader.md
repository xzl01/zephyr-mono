# RSS 资讯阅读

资讯支持最多 4 个 RSS 2.0 订阅。顶部栏目切换，内容中心网页负责增删修改；每源有独立
SD 缓存、更新状态和正文版本。打开或下拉只请求当前源，没有定时全源轮询。

## 订阅管理

- 默认「金价」来自 `CONFIG_PAPERMONO_RSS_URL`，默认「AI 资讯」来自
  `CONFIG_PAPERMONO_RSS_AI_URL`；第二个地址为空时不添加该源。旧 `rss_url` 设置不承担多源存储。
- 配对后在内容中心的「资讯订阅」新增、修改、移除，再按「保存订阅」。支持保存空列表；
  未保存的输入在网络失败后保留，重新加载会提示放弃草稿。
- 每源有稳定 `id`、显示名称和 `http://` 地址。ID 最多 15 字节，名称最多 47 字节，
  URL 最多 191 字节；非法 UTF-8、空白名称、重复 ID/地址及不能抓取的地址会被拒绝。
- 配置通过 `GET/PUT /api/v1/rss/sources` 管理，均要求已配对会话；完整列表原子保存，
  TF 不可用或写入失败保留原配置。接口格式见 `content-api.md`。
- 来源顺序变化时按 ID 保留选择；当前源被删除则回首项。修改 URL 会使用另一份缓存，
  不会把旧地址内容当作新地址结果。

## 调度与连接

开机仅创建 worker 并尝试恢复缓存，不主动轮询。打开、切换来源或第一页下拉时，
UI 调用显式 source API；最近缓存、RTC 未校准都不阻止请求。缓存可立即阅读。
排队或执行中的同源请求合并，不同源独立记录状态。

单 worker 共享响应缓冲。失败最多尝试 3 次，间隔 20 秒；退避期间若其它源被请求，
在 1 秒内结束当前轮并让出，其后当前源可重新打开或下拉重试。DNS/连接返回检查及
收发循环受 30 秒总期限约束，单次收发空闲上限为 10 秒，按总剩余时间裁剪。
DNS/连接本身仍受 Zephyr 栈的阻塞期限控制，返回后检查总期限。

TCP socket 绑定站点接口的具体 IPv4，避免 STA/AP 并存时跨接口选源。只固定该连接，
不修改全局默认接口或热点服务。失败包含 SD、地址、网络错误，均结束同步状态并通知页面。

请求冻结来源身份及代次：管理列表被修改、删除或重排后，旧请求完成不能覆盖新的来源。
成功后只更新该源的 revision；当前正文仅在自己的源版本变化时重载。

## SD 缓存

根目录 `/SD:/papermono/rss/`：

- `sources.bin`：固定版本、CRC 校验的来源注册表；通过 `sources.tmp` 和 `sources.bak`
  原子替换并恢复中断。空列表也是有效配置。
- 每源在稳定 ID 与 URL 指纹生成的子目录存储 `source.bin`、`index.bin`、`bodies.bin`；
  完整身份记录校验 ID 和 URL，避免指纹碰撞或配置变化串用内容。
- `index.bin` 保留固定 2112 B 索引；正文按序放入 `bodies.bin`，只有打开一篇时才读回。
  正文/索引通过 `.tmp`、`.bak` 成对提交和回滚。
- 原单源目录文件保留，不盲目归入身份未知的新来源；升级后来源首次请求会建立独立缓存。

## 表格与正文

正文仍使用单篇 64 KB UTF-8 缓冲，普通无表格旧内容兼容。HTML 表格在原位编码为
内部行记录：`RS T1` 开始、`RS H` 表头、`RS R` 数据行、`RS E` 结束，格间 TAB。
`RS` 为 `0x1e`，外部正文中的同名控制字节被移除，不能伪造表记录。

- 段落、标题、列表、引用以及表格前后说明保持原先顺序；单元格内部换行转空格。
- 每组显示首列和最多两列数据，宽表分组，表头和首列用于跨页对照。
- 单元格换行；超高行按完整文字行续页，不能用省略号截掉长观点。
- colspan/rowspan 展开空占位；超出有界跨行/跨列能力时明确降级为顺序文字。
  嵌套表在外层单元格内压平，不破坏外表列序。
- PSRAM 中保存轻量块/行/页索引，仅物化当前页对象，正文由静态标签引用，不复制整表。
  超过 256 块、4096 行或 4096 页时明确降级为完整纯文本，保留全文尾部。
- 正文和表格共用文章页号；列组标在页脚，侧键或上下滑动按顺序翻页，点按回列表。

普通正文保留段落、标题、列表与引用；script/style 丢弃，URL 缩短为 host/首段，
连续空行合并，去掉重复开头标题。

## 界面与边界

列表顶部为来源文字标签与下划线，元信息仍在 y=56，八行索引从 y=80 起。
第一页触摸下拉刷新当前源；第二页下拉回上一页，正文与实体键保持原阅读导航。
同步中和错误提示显示于元信息行，缓存仍可读；零源、空订阅、无缓存与失败分开提示。

每源最多 12 篇；单篇正文 64 KB、每源正文合计 256 KB；响应缓冲 128 KB，满时丢弃
不完整尾条。金价源大于该上限，因此一次抓取未必包含源内全部条目。此轮没有扩大响应缓冲。
仅支持明文 HTTP；无原文 link 字段。新增大状态和索引放 PSRAM，内部 DRAM 继续遵守 85% 门槛。

最新原生与网页参考：`docs/design-references/rss-multisource-20261028/`。原生 fixture
使用真实 UI、LVGL 和表格 codec，但 RSS/网络/SD 为合成状态；网页预览使用本机 mock API。
